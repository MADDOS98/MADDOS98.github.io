Git & GitHub pentru proiecte

Acasă Despre Git Lucru în echipă

Crearea unui nou proiect Git

mkdir proiect-nou
cd proiect-nou
git init

Adăugarea și commit-ul fișierelor:

git add .
git commit -m "Inițializare proiect"

Conectarea la GitHub:

git remote add origin https://github.com/utilizator/proiect-nou.git
git push -u origin main

Urmărirea versiunilor

git log

Crearea unei ramuri noi:

git checkout -b feature-autentificare

Ramurile (branches) sunt esențiale pentru a dezvolta funcționalități fără a afecta codul principal.
