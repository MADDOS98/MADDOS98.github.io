Colaborare prin GitHub

Lucrul în echipă implică utilizarea branch-urilor, pull requests și review-uri de cod.

Crearea unui branch:

git checkout -b fix-bug-123

Trimiterea modificărilor pe GitHub:

git push origin fix-bug-123

Pull Request

Pe GitHub, deschizi un Pull Request (PR) pentru ca ceilalți membri să revizuiască codul tău înainte de a-l integra în main.

Rezolvarea conflictelor

git merge main
# Dacă apar conflicte, editează fișierele și apoi:
git add .
git commit

Actualizarea locală a proiectului

git pull origin main

Lucrul colaborativ eficient se bazează pe comunicare și commit-uri clare.
