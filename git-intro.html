Ce este Git?

Git este un sistem de control al versiunilor creat de Linus Torvalds în 2005. Permite urmărirea modificărilor aduse fișierelor și revenirea la versiuni anterioare.

Inițializare depozit Git:

git init

Adăugarea fișierelor:

git add nume_fisier.txt

Crearea unui commit:

git commit -m "Mesajul commit-ului"

Ce este GitHub?

GitHub este o platformă de găzduire a codului care folosește Git. Poți stoca, partaja și colabora la proiecte.

Exemplu de clonare a unui repo:

git clone https://github.com/utilizator/proiect.git

GitHub oferă și funcții sociale: urmărirea altor utilizatori, issue-uri, wiki și pull requests.
